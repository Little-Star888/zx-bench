# 结构变化候选实验：实测与取舍

**首轮没有解决天花板问题，五个题族暂不进入正式评测。** DeepSeek 与用户当前复测模型 Qwen-NVFP4 对新五类题均全部答对，首批设计未达到难度预期。结构变化可以检查是否理解条件，但不会自动把一个可按规则执行的小问题变成高难问题。

设计、命令和评分说明见 [实现说明](structural-challenge-2026-09-14.md)。本轮开发包摘要为 `b8c620bdc93c80716b88e770495932249e14a50ea24e57e406598aee41864dbe`。所有数值来自保存的回答，不使用 LLM Judge。

## 首轮边界

开发包共 15 题：数学 8、提取 3、幻觉抵抗 4。每族仅 1 个独立实例，变体不当作独立样本。各模型每题新上下文、单次作答、不使用外部工具，输出上限 32768 token、时间上限 300 秒。DeepSeek 沿用已有 thinking/max 设置；本地 Qwen 使用 temperature=0.6、top_p=0.95。它们不是等算力比较，也不能直接对照旧正式评测的不同预算。

DeepSeek 请求名 `deepseek-v4-flash`，服务端记录名 `deepseek-flash`。15/15 正确，数学、提取、幻觉抵抗均 100。服务端汇总 completion_tokens 为 121864，请求时延合计 479.201 秒。其中有限最优证书题使用 31098 completion_tokens，仍得到了正确证书：这体现求解成本，没有产生正确率分差。

GLM 首次请求返回 HTTP 429，随后停止；三个维度为空。不能将其算作 0 分或“弱模型”，也没有把这次失败包装成能力区分。

| 模型 | 数学（8 题） | 数据提取（3 题） | 幻觉抵抗（4 题） | 全对题数 |
|---|---:|---:|---:|---:|
| DeepSeek，服务端返回 deepseek-flash | 100 | 100 | 100 | 15/15 |
| 本机 qwen3.8-27b-nvfp4 | 100 | 100 | 100 | 15/15 |
| GLM | 未测得 | 未测得 | 未测得 | 首次 HTTP 429 后停止 |

两次完整运行均无超时、截断和格式失分，五个题族的内容分差均为 0。本轮实际发出 31 次请求：30 次完成作答，1 次 HTTP 429。对于这个开发实例，“未形成正确率区分”有直接证据；样本量不足以断言整个生成分布必然饱和。

逐题和逐族结果：`reports/structural-challenge-2026-09-14-v1/final-screen.json`。原始回答分别在 `deepseek/`、`qwen-nvfp4/`，运行预算见各自 `plan.json`，冻结原题及参考答案在 `development/`。正式晋级决定见 `release-decision.json`；仓库内保存精简证据 [本轮证据摘要](structural-challenge-2026-09-14-evidence.json)。

## 旧提取成绩：评分贡献能解释多少

对 `zxbench-pro-2026-09-13T11-26-49-528Z-7886d975` 做只读拆分，使用该次运行冻结的题目权重，而非当前题库重算：

| 指标 | 数值 |
|---|---:|
| 原数据提取加权成绩 | 90.62 |
| 仅取已有字段准确率轴、保留同样权重的交付诊断 | 85.38 |
| 差值 | 5.24 |
| 满分题 | 38/56 |
| JSON 解析失败 | 3/56 |

该 85.38 是已保存评分轴的拆分，**不是新 F1 判分器对旧回答的重评成绩**。解析失败的内容没有被测量，仅在交付诊断中计零；字段轴本身已经逐题四舍五入。

具体例子：DE-CN-006 与 DE-CN-056 均只有 4/5 字段正确，却得 92；DE-CN-018、DE-CN-031 为 3/4 正确，却得 90。因此格式/结构的高占比确实遮蔽内容错误，但这次运行中只解释约 5.24 个加权分，不能把全部天花板问题归咎于评分权重。原来就全对的 38 道题，更换权重也仍然全对。

证据：`reports/structural-challenge-2026-09-14-v1/legacy-extraction-decomposition.json`，含逐题原分、字段轴、冻结权重及准确字段数。

## 当前取舍

保留可复用的机制：内容与格式分开、无固定结构保底、单次作答与预算留痕、精确证书验证、题面/答案/代码冻结、题族级筛查、反事实与重排诊断。五族均记录为 `not_promoted_observed_ceiling`；这只是当前候选的拒绝决定，不声称其他实例已被完整校准。

不将这批题直接作为已校准高难题上线。尤其是：

1. 数据提取仍主要从整齐的 JSON 事件中执行给定规则，实体边界和候选字段已经高度显式。这比真正从杂乱自然文档恢复关系容易。
2. 幻觉抵抗仍主要匹配显式范围和证据状态。它检查“按给定规则选哪条证据”，对“证据能否推出一个未直接写出的结论”覆盖不足。
3. 数学虽然改变了抽样测度、可识别状态和 LP 状态，仍是小网格枚举、短程概率枚举与低维线性规划。可以稳定核验答案，不代表处于目标模型的能力边界。

这也修正了此前建议中偏乐观的部分：**“更多结构变化 + 更严格验证”仍不是难度与区分度的充分条件。** 下一轮筛选需要同时观察正确率、真实内容错误、求解成本和实例间稳定性；如果低分主要来自截断、格式或新聚合规则，就不能算整改成功。

30 题 confirmation 包已提前冻结，本轮未调用模型作答。共享题族的新实例确认，仍不能补足未知题族覆盖；在开发筛查仍饱和时，不应继续花预算把同一过易题族扩成大题库。
