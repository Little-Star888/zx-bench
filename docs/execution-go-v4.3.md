`isolated-go-json-v1`只接受四种固定适配器与严格数据形状。固定镜像为`zxbench/go@sha256:bbe499b0985c0481a47548381d03e2a46ded78e13411b8e5865b0efbdb391e03`；本地镜像限定、禁网、只读根与工作区、非root、资源及时限约束开启。Go编译器需要更大的可写缓存且生成本机二进制，因此容器仅为该协议启用128 MiB可执行`/tmp`；仍保持capabilities全移除、`no-new-privileges`、禁网与只读题目文件。

候选只看到输入与固定驱动，看不到测试ID、期望或分数。宿主比较排序后的channel值、切片修改后的原值、`errors.Is`结果、解析返回值或Counter最终计数。Counter使用`go run -race`，race detector以非零退出形成独立失败证据；返回1000但存在数据竞争仍失败。该协议不泛化为调度/泄漏或性能核验，因此FanIn、First等题仍保持未迁移。
