# 大幅提难实验：全局优化、证据蕴含与自然档案重建

上一轮五族十五题在 DeepSeek 与 Qwen-NVFP4 上全部满分，因此本轮不再以“结构稍有变化”作为难度证据，直接构建三个规模档的挑战题。**档位先表示构造规模，实际难度和区分度必须经实测确定。** 内部模块名 frontierChallenge 不表示已达到 FrontierMath 或研究级证明难度。

## 题目改变

| 维度 | 前轮 | 本轮档 1 / 档 2 / 档 3 | 主要要求 |
|---|---|---|---|
| 数学 | 4 变量、8 约束的连续 LP；最优见证由生成器直接构造 | 16 / 22 / 26 个二元变量，当前实例 54 / 89 / 135 条混合正负权边 | 在费用、选取个数、交叠奇偶约束和蕴含约束下求二次目标的全局最优；搜索空间上限 65,536 / 4,194,304 / 67,108,864 |
| 幻觉抵抗 | 判断显式证据范围及修订状态 | 12 / 16 / 20 个未知站点状态，交叠汇总材料，每题 6 个结论 | 区分所有可能解释均成立、均不成立、两种解释都存在；结论不能靠单条材料决定，必须组合证据 |
| 数据提取 | 3 个实体、结构化 JSON 日志 | 8 / 16 / 24 个初始实体，53 / 103 / 151 条流水版本或重传，正文约 6.6k / 12.3k / 17.9k 字符 | 从打乱的邮件、仓务单、附页与裁定中恢复最终记录；柜号换绑、版本替代、批次撤销、条件划转相互影响 |

数学有一个保证可行的初始构造，但**不预设最优解**。金标来自遍历全部 0/1 状态，使用 Gray code 增量更新目标；记录精确最优值、达到最优的见证及最优解数量。另用 SciPy/HiGHS 将 XOR 线性化成整数规划，独立证明最优，并检查整数见证和对偶界。三个开发实例均一致。

幻觉题不披露每个站点的结果，只披露重叠分组人数。支持某个结论需要该结论在全部符合资料的完整状态中成立；“找到一个支持它的名单”不充分。“无法确定”则要提供成立、不成立的两个可行完整状态，不能靠一律拒答得高分。生成器排除了能由一条汇总记录及其简单子集界单独决定的支持/否定结论。金标通过枚举所有状态得到，并另用整数规划独立求每个结论的最小/最大人数，共 18 个结论全部一致。

提取题中特别增加了不可通过简单反向加减处理的撤销：某批入库一旦撤销，后续划转可能由于余额不足而根本不生效；必须从保留的历史流水重放。正式修订整份替代旧版、草稿不替代、未来登记不纳入当前视图，柜号按业务时间换绑而非按材料排列或登记时间换绑。正文没有完整金标 schema 的逐槽 null/数组长度提示。

## 判分与边界

- 数学：全局最优值和达到该值的可行 0/1 解同时正确才通过。另报可行性、申报值与见证是否一致、绝对及相对最优性差距。全局搜索能力是本题的测量对象，不宣称测出了自由形式证明能力。
- 幻觉：逐结论计算“状态正确率”和“状态及见证均正确率”，两者分列。见证错误是具体的证据约束违背，不归类成 JSON 格式错误。本题测封闭材料的逻辑蕴含与过度断言，与数学推理有交叉；不能单独代表开放世界知识幻觉。
- 提取：按实体 ID 对齐后计算字段内容 micro-F1，多余实体、额外字段和缺失字段都会影响分数；记录顺序不计错。没有格式/完整性/类型的固定保底分。
- 格式策略沿用前轮：唯一 JSON 或唯一代码块中的 JSON；附加说明不参与数学证明评分，格式合规另报。
- 超时、截断、不可解析与已验证内容错误分开。交付分包含预算内未交付的影响；纯内容均分只有计划题全部被内容判分时才提供。基础设施失败或缺题不得被成功样本均值掩盖。

三个档不是严格控制变量的单调难度实验：实例内容随档位一起变化；较多变量的证据题也可能因为约束结构更简单而更容易。不能用单个实例据此宣称“档 3 一定最难”。目前每档每族一题，尚不足以校准难度、拟合 IRT 或验证稳定排名。

## 本轮试跑

开发包 9 题、两个模型各一次，共计划 18 次作答。每题独立上下文，不给工具，无自动重试和择优，无 Judge。预算提高到 **90,000 output token、600 秒/题**；两模型各自串行，最多两个在途请求。Qwen 沿用本机已加载的 `qwen3.8-27b-nvfp4`，不切换模型；发现正式评测运行时停止发出后续请求。DeepSeek 使用项目原有配置，并保留服务端实际返回的模型名。不同服务的 thinking 参数与吞吐量不代表同等算力。

如果全部失败，首先区分是预算失败、可行性错误、非最优，还是正确结论配错见证。只有全零而没有可靠的表现差异，是地板效应，不计为解决了区分度。反过来，若只有最后一档出现实质内容分差，可将它作为新实例复验的候选，不把前两档混入总分稀释差异。

## 第二条数学路线：有限域算子计数

首轮全局优化题出现预算失败，因此另行冻结三道以子空间、核、商空间及秩条件为核心的计数题。题目要求计算有限域 F₂ 上七维空间中的有序算子对，满足 A²=B²=AB=BA=0、两个算子的秩均为 2，并分别约束像空间交集、核相等或和算子的秩。不按共轭取商。允许返回精确乘积表达式，避免必须展开大整数造成额外误差。表达式由有资源上限的有理数解析器检查，不执行模型代码。

这组三题不叫“三级难度”：相近条件可能触发不同解法，必须按实例报告。它们属于本轮观察后的探索性补充；独立冻结，未混进事先冻结的九题包，也不宣称是留出集验证。

### 金标推导

记 r=rank(A)、s=rank(B)、t=dim(im A∩im B)，d=r+s−t，m=n−d。四个零乘积条件等价于 W=im A+im B 被 A、B 同时消去。先选 d 维的 W，再选其中有给定交集维数的有序像空间 U、V，最后选从原 n 维空间对 W 的商空间到这两个像空间的满射。

记 G_q(n,k) 为高斯二项式，S_q(m,r)=∏_{i=0}^{r−1}(q^m−q^i)。像空间选择数为

`I = G_q(n,d) × G_q(d,r) × G_q(r,t) × q^((r−t)(s−t))`。

无核限制时，总数为 `I × S_q(m,r) × S_q(m,s)`。核相等且 r=s 时，满射对因子改为 `G_q(m,r) × |GL(r,q)|²`；r≠s 时核不可能相等。核不同时取两者之差。金标公式另与三、四维有限域上的秩一算子直接枚举交叉核验。

第三题再限定 rank(A+B)=2。选定公共像空间的基后，可写 A 的非零行为 (a,b,0)、B 的非零行为 (c,0,d)，其中 a,b 及 c,d 分别线性无关，a,b,c,d∈F₂⁴。问题化为 rank(a+c,b,d)=2。枚举四个商空间行向量只有 44,100 个满射对；不枚举原始七阶矩阵对。独立手工计数按 b,d 是否独立分两类：

`15×14×(12×4+2²) + 15×14×12 = 13,440`。

再乘相应的像空间选择数，与枚举金标一致。把正确的精确表达式判对，但不据此宣称已经核验了模型自由形式证明的每一步。

## 验证

新增 9 项测试覆盖 Gray code 与直接枚举交叉检查、手解可能世界、错误见证、非最优可行解、撤销导致后续划转失效、空值和内容 F1、题包及提交身份、格式与内容分离、预算失败不能制造区分、全零不能晋级、算子计数与独立枚举，以及精确表达式判分。独立整数规划分别复核开发包、提前冻结的新实例确认包的全部数学题和证据题，共 12 道题的金标一致。`scripts/audit-frontier-structure.py` 另用 Python 重放两个包的六份账本，全部与金标一致，并独立审计证据题的可行世界、固定变量和决定结论所需的最少报告数。

本机独立核验环境为 Python 3.14.3、NumPy 2.4.3、SciPy 1.17.1。结构审计使用 NumPy 2 的 `bitwise_count`；整数规划使用 SciPy 的 HiGHS 后端。核验脚本只读取本地冻结题包，不调用模型服务。

全量测试：1520 通过、213 跳过、0 失败；138 个测试文件通过。core 构建和类型检查通过。集成测试中原本需要另行启用的容器用例没有被宣称为已执行。
