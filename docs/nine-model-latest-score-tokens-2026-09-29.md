# 九模型最新版成绩与 token 用量（2026-09-29 定向补跑）

## 统计口径

本报告以先前完成 Judge 同义复核的九模型成绩为基线，并入修订题面/执行契约的 15 个任务实例在九模型上的 135 份新作答、13 份模型专属旧超时实例补答，以及 Signal 的保存轨迹离线重判。定向补跑共 148/148 次。189 道 Docker 迁移来源题仍按 306 个任务实例等权折算；60 道结构化输出及其余 554 道来源题沿用已采纳答卷。

修订了题面或执行契约的实例与旧卷运行条件不同，下面的增分是成绩口径更新，不能解释为模型在相同题面上的能力提升。九模型综合分是已保存结果的新版合成对照。Signal 原正式数据库记录仍为 72.30；本报告的 Signal 73.60 是并入最新定向结果后的对照分，未覆盖原运行。

## 核验与限制

- 八模型并入前的 189+60 题 token 汇总与既有 `token-usage-summary.json` 逐模型一致；Signal 的旧 803 题输入、输出总量与正式运行 summary 一致。
- Signal 旧迁移轨迹离线重判 4 个任务实例，其中 3 个已由先前 Judge 同义复核更正，此次没有重复加分。
- 新补跑的 0 分记录里有 5 条只缺少最终答复中的具体政策条款；答复仅说已总结或发送，未说出每周天数和审批要求，未据此增加同义表达分。
- CLI-CN-027 的验收路径修复由保存脚本离线重放验证；定向结果摘要中已采用其更正分。
- 最新补跑结果保存在另一工作树，原正式数据库和八模型原始答卷保持可追溯；本报告为并入后的对照分。
