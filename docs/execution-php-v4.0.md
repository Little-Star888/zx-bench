## 共用可信边界

`isolated-php-json-v1`使用固定摘要的PHP 8.2 CLI镜像、只读根和工作区、非root用户、禁网、内存/CPU/PID/输出/时间限制。候选容器只收到候选源码、固定数据驱动和当前输入；测试ID、期望值、断言、得分均不进入容器。宿主解析唯一JSON输出并严格比较类型、长度和值；退出、超时、输出溢出、额外日志或伪造分数都不能授予通过。

该通道只认证给定输入上的JSON返回数据。候选仍与PHP驱动处于同一进程，不能据此认证内部调用、恒定时间、复杂度、引用身份或一般沙箱逃逸安全；也不承诺PHP所有扩展。恶意实现始终可以针对输入硬编码，和任何有限黑盒测试一样，需要后续独立挑战题降低过拟合风险。

标签清洗第二个旧断言先调用`array_values`再比较。协议因此只为该调用执行固定内置`arrayValues`投影，其他调用为`identity`；投影枚举及数量严格校验，不能注入代码。没有把自然正确但保留键0/2的实现收紧成必须主动重排索引。其余17个测试均直接比较返回值。
