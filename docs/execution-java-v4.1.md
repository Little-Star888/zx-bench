## 共用边界

`isolated-java-json-v1`使用固定摘要JDK 17镜像、只读根/工作区、非root、禁网及内存/CPU/PID/输出/时间限制。五种适配器是封闭枚举，仅把严格校验的JSON输入构造成题面已有的`int[]`、`Money`、`Integer`、`BigDecimal`或字符串调用；不接受任意表达式、类名或测试源码。候选容器收到输入和固定驱动，不收到ID、期望、断言或得分；宿主对唯一JSON输出执行精确值或原题数值容差判断。

该通道只认证指定输入上的返回值和HashSet大小/哈希相等观测。候选与驱动仍在同一JVM，不能据此认证一般对象身份、完整JVM隔离、内部调用、并发、资源或性能。有限黑盒测试仍可能被输入硬编码，后续挑战题与独立金标仍有必要。
