注册表含 293 个执行任务包：288 个开发包，5 个基础回归包。一个原题可有多个状态变体，不能把包数当作原题数。本批对 12 道未满足饱和退役条件的既有 easy 原题仅作一对一搬迁，没有增写基础题。新任务沿用源题 ID 并加执行后缀，仍在 `private_dev`，未替换正式题和历史成绩。

CLI 题在隔离容器中实际运行脚本并检查输出、文件或 Git 状态；工具与智能体题使用容器内可重置的本地状态、文件、SQLite、HTTP 进程等，按调用结果、终态和禁止副作用评分。邮件、资金等是模拟账本，不触达外部业务。若原题要求一般性的文档转换或渲染，开发 fixture 只证明提供的样例能力，不证明通用转换能力。

每个注册任务包都有参考解和核心错误示例。检查报告含题目、执行器、验证器及脚本指纹，匹配时复用；指纹失配才重跑。最终核对的 293/293 个包均有匹配当前指纹的通过报告，参考解分数均为 100，核心错误示例均未达到严格成功；题库与数据库定义无状态或哈希漂移。这个检查只证明给定正反样例能被区分，不证明评分无漏洞，也不证明对模型有足够区分度。

当前阶段结束的是**原题到 Docker 开发环境的覆盖迁移**。新增开发任务尚未用用户指定的两个模型系统校准，合法替代路径和难度仍需审查；正式题库切换、完整 CI、跨机器镜像可复现性与 GitHub/release 发布均未在本批完成。使用的镜像在本机按 ID 固定，另一台机器需要准备相同镜像。
