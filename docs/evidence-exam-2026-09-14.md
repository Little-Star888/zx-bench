# 数据提取与幻觉抵抗：十二套递进式大题

本题包已从两道机制样例扩充为数据提取 12 道、幻觉抵抗 12 道，共 24 道大题、96 个小问。每题按 10/20/30/40 分递进，第三、四问各限制 1200 秒；小问单独交卷，超时保留此前已经完整提交的评分项。

数据提取覆盖订单退款、设备更换、样本谱系、库存重放、双时态事件、合同修订、统计口径、会议决议、阶梯计费、批次召回、权限快照与实体解析。末问重点处理同级冲突、追溯更正、无法换算、不可追溯和局部未知，不能通过单纯延长流水或照抄最近一行解决。

幻觉抵抗覆盖追溯更正、独立来源冲突、不完备名册、条件例外、统计口径、因果不可识别、计划与事实、实体歧义、引用断链、时间有效性、不完备规则及局部矛盾。每题同时包含可确定和不可确定项；统一拒答、统一采信最新材料或因一个冲突拒绝整题都会失分。

新结构化题按答案树叶子计算内容 micro-F1。缺字段、错值及额外猜测都会影响得分；核心状态判断错误时本问最高 50%，其他内容字段错误时最高 80%，不设置 JSON 格式保底分。DX3-05 继续使用双时态事件核验；HX3-11 继续要求确定结论的合法极小支持集，或不确定结论的正反模型见证。参考答案只保存在协调端，导出的模型题面不含金标、评分结果或未来小问。

题包状态为可显式运行的 prospective 轨道。确定性参考重放全部满分，说明题面、金标与评分接口一致；这不代表新题已经通过模型难度校准。正式排行榜成绩仍需有限的前瞻筛查，不能把“设计为超高难度”直接写成已证明存在区分度。

```powershell
pnpm eval:exam:evidence export reports/evidence-exam-review
pnpm eval:exam:evidence grade reports/evidence-exam-review path/to/submission.json reports/evidence-exam-result.json
```

导出目录必须尚不存在。模型只接收 `candidate-questions.json` 或 `题面.md`；`coordinator/` 下的冻结题包和参考答卷不得发送给模型。编题阶段没有调用模型服务，也没有重算历史成绩。
