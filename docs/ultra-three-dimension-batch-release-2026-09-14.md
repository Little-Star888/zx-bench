# 三维超高难度递进题集发布说明

本次按最初范围同时建设数据提取、数学推理和幻觉抵抗。统一轨道包含每维度 12 道大题、每题 4 个递进小问，共 36 道大题、144 个小问。第三、四问上限均为 1200 秒；规定时间内提交多少就按多少评分，后问未完成不清空前问得分。

数学轨由 UMX-01、UMX-02 和十道尚未实测的 MX3 候选组成。两道 UMX 的两模型筛查成绩为 33.0 与 38.5，没有天花板；MX3-06、MX3-12 因两模型全卷满分被明确排除。其余十道 MX3 只是冻结的 prospective 题，不能在没有实测前宣称达到同样区分度。UMX 使用结论、证明、完成度 rubric 和语义封顶；自然语言证明的正式分数需要独立复核。

数据提取 12 题不再依赖单纯拉长流水，重点加入局部冲突、字段级修订、实体与批次谱系、不可追溯、重放失效和不完整信息。结构化答案按内容叶子 micro-F1 评分，多猜字段同样产生惩罚；核心状态错误最高 50%，其他内容错误最高 80%，不设置格式保底分。

幻觉抵抗 12 题把“能答”和“不能确定”放在同一道大题中，覆盖来源独立性、闭合范围、条件例外、因果识别、实体歧义、引用断链、时间效力及局部矛盾。HX3-11 继续使用可执行的极小支持集和正反见证核验；其他题逐字段核验判断、有限结论和来源。

题面逐问导出，只携带同一大题此前已提交的答案，不发送协调端金标、得分反馈或未来小问。统一清单位于 `data/scenarios/ultra-batch-release-manifest.json`。该轨道已经可以显式运行，但新增加的数据提取、幻觉抵抗和十道 MX3 尚未完成难度校准，因此暂不直接产生正式排行榜名次，也不改写历史成绩。

本次只做必要的确定性验证：三维题号与题量核对、全部结构化金标重放、评分抗多猜检查、题面泄漏静态检查、相关单元测试及 core 类型检查。编题本身不消耗模型调用。

统一题面包可离线导出，不会请求模型：

```powershell
pnpm eval:ultra:batch export reports/ultra-three-dimension-review
```
